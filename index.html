Por que confiar nesses alertas

Cada sinal foi testado contra as obras já encerradas da sua própria planilha: a barra mostra quantas das obras com aquele sinal terminaram mal. A linha preta é a média geral () — barra à direita dela = sinal de perigo real.
"Problema" aqui sempre significa status Cancelado, Sem Evolução ou Paralisado Com Termo — nunca uma obra só porque está atrasada. Ver a lista completa de obras com problema →

🏢 Empresas problemáticas

Ranking de risco das contratadas

Empresas com 5+ contratos, ordenadas pelo índice de risco (0–100). A faixa mostra a carteira: ■ concluída · ■ em andamento · ▨ paralisada/sem evolução · ■ cancelada
Índice de risco = 60 × taxa de contratos com problema (cancelado, sem evolução ou paralisado) + 40 × taxa histórica de paralisação. É triagem, não julgamento definitivo.

Fonte de dados

O painel busca os dados na API do Apps Script. Sem URL configurada, tenta um arquivo data.json na mesma pasta.
A URL e a chave ficam salvas só neste navegador, neste computador — não são enviadas pra nenhum outro lugar nem sincronizam entre dispositivos. Cada pessoa da equipe configura uma vez, no próprio aparelho.

Importante: se seu Apps Script está publicado como "qualquer pessoa com o link", quem tiver essa URL consegue ler a planilha, mesmo sem estar aqui no painel. Configurar uma chave de acesso no Code.gs (propriedade API_KEY) fecha essa brecha — sem a chave certa, a API recusa o pedido.
