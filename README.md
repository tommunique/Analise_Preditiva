# Painel de Obras — Piauí

Dashboard de acompanhamento de obras públicas do Piauí, a partir da base de contratos do estado.

Demo: https://tommunique.github.io/Analise_Preditiva/

## Conteúdo

- Situação da carteira (concluídas, em andamento, paradas, canceladas).
- Alertas de risco por obra (paralisação, estagnação, empresa com histórico de problemas).
- Valor em risco.
- Distribuição de problemas por órgão e por tipo de obra.

## Arquivos

- `index.html` — aplicação.
- `data.json` — base de dados das obras.

## Stack

HTML/JS puro, sem backend.
